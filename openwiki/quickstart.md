
# Quickstart: Employee Management System

Welcome to the Employee Management System, a full-stack application built with Angular and ASP.NET Core. This document provides a high-level overview of the project and guides you to more detailed documentation.

## Project Overview

This project is a hands-on example of a modern web application, demonstrating best practices in both frontend and backend development. It includes features like JWT-based authentication, role-based authorization, and a clean, modular architecture.

### Tech Stack

- **Frontend:** Angular 20, TypeScript, Angular Material
- **Backend:** ASP.NET Core 8.0, C# 12
- **Containerization:** Docker
